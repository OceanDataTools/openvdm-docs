OpenVDM is a ship-wide data management platform for research vessels. It retrieves
and organizes files from multiple instrument and data-acquisition systems into a
unified cruise data package, with web-based access and a plugin architecture for
custom data processing.

## Key Features

- **Automated data ingestion** from local directories, rsync servers, SMB shares,
  SSH servers and FTP servers
- **Cruise data transfers** to backup drives, NAS, servers and rclone cloud remotes
- **Cruise and lowering lifecycle management**: create, monitor, and finalize cruise
  and dive/lowering data packages
- **Data dashboard** with maps, time-series charts and depth profiles, generated by
  plugins, including parsers for Sea-Bird CTD and MK21 XBT casts
- **Ship-to-shore transfer** of selected data, by priority, to a shoreside data warehouse
- **Extensible plugin system** for custom per-file parsing, statistics and quality tests
- **Web-based administration** for managing transfers, extra directories, and hooks
